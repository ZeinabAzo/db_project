# db_project

Full-stack sports ticket booking platform for football, volleyball, basketball. Fans search &amp; reserve seats with real-time locking, pay via simulated bank API, cancel with refunds. Admins manage. REST API (Node/Express, PostgreSQL, Redis, JWT, OTP login). Multi-phase: ERD, backend, frontend, Docker, PaaS deploy, CI/CD.

## Project Phases

Please check the **branches** of this repository to review the different phases of the project.

**Phase 1 and Phase 2 were developed and maintained in separate branches within this same repository.** Please switch to the corresponding branch to access the complete implementation and files for each phase.
